An LSAT assumption question asks for a premise the argument leaves unstated, and it comes in two kinds: the assumption the argument requires, and an assumption that would make its conclusion follow logically. Detecting assumptions made by particular arguments is one of ten skills LSAC lists for its Logical Reasoning questions (LSAC, 2026). The two kinds are tested differently, so the first step is to tell them apart.

Two Kinds of Assumption Question

LSAC's sample questions include one of each (LSAC sample questions, 2026). One asks "Which one of the following is an assumption required by the argument?" LSAC's explanation puts the task this way: find the statement whose truth is required if the argument is to succeed in demonstrating its conclusion. This guide calls that a necessary assumption. The other asks "The conclusion drawn above follows logically if which one of the following is assumed?" There the task is to identify the option containing information that makes the conclusion of the argument follow logically. This guide calls that a sufficient assumption.

The difference decides which answer is right. A necessary assumption is something the argument cannot do without, so it need be no broader than the argument itself. A sufficient assumption only has to close the gap, so it can be broader than the argument needs.

How to Find a Necessary Assumption

  1. Find the conclusion and the premises. Say in a few words what the argument claims and what it offers as support.
  2. Name the gap. Ask what the support leaves out, such as a link between two terms or a cause the argument takes for granted.
  3. Negate each choice. Suppose the choice is false. If the conclusion then no longer follows, the argument needed it. LSAC's explanation of its sample picks its answer by this test: if the choice is false, the conclusion of the argument would not follow.

Here is an original example.

Sales of umbrellas at Corran's shop doubled in March. It rained on more days in March than in February, so the rain must have caused the rise in sales.

Which one of the following is an assumption required by the argument?

(A) It rained on more days in March than in any other month that year.

(B) Corran's shop sold more umbrellas in March than any other shop in the town.

(C) Whether it rains affects how many umbrellas people buy.

(D) Most of the umbrellas sold in March were bought on days when it rained.

(E) Corran's shop charged the same for its umbrellas in March as in February.

Negate (C): whether it rains has no effect on how many umbrellas people buy. Then more rainy days cannot explain more umbrellas sold, and the conclusion no longer follows, so (C) is the answer. Negate (D): most of the umbrellas were bought on dry days. The rain could still have caused the rise, since people buy an umbrella before the next shower as well as during one, so the argument survives. (D) would strengthen the argument, but the argument does not need it. The same goes for (E): a different price in March, such as a cut, would give a second possible cause, but the rain could still have caused the rise. (A) and (B) say nothing the argument relies on. The answer is (C).

How to Find a Sufficient Assumption

  1. Find the conclusion and the premises, as before.
  2. Name the gap. Ask what link between the premises and the conclusion is missing. In the example below, the premises speak of apprentices who finished the safety course, and the conclusion speaks of apprentices in general.
  3. Add each choice to the premises. If the conclusion is then guaranteed, the choice is sufficient. It does not matter whether it says more than the argument needs.

Here is a second original example.

Every apprentice at the Ferrand works who finished the safety course was given a key to the store. Tomasz was given no key to the store. So Tomasz is not an apprentice at the Ferrand works.

The conclusion drawn above follows logically if which one of the following is assumed?

(A) Every apprentice at the Ferrand works finished the safety course.

(B) Everyone given a key to the store is an apprentice at the Ferrand works.

(C) Tomasz did not finish the safety course.

(D) Some apprentices at the Ferrand works were not given a key to the store.

(E) Only apprentices at the Ferrand works take the safety course.

Add (A). If Tomasz were an apprentice, he would have finished the safety course, and then he would have been given a key. He was given none, so he is not an apprentice, and the conclusion follows. (A) says more than the argument needs, since only Tomasz matters, so it would fail the negation test for a necessary assumption: another apprentice could have skipped the course without harming the argument. (B) and (E) run the wrong way: each says who the apprentices include, not what every apprentice did. (C) leaves open that Tomasz is an apprentice who never finished the course, and (D) is consistent with him being an apprentice. The answer is (A).

Necessary vs Sufficient at a Glance

Necessary assumptionSufficient assumption
LSAC's wording"an assumption required by the argument""follows logically if which one of the following is assumed"
What the answer doesMust be true for the argument to succeedMakes the conclusion follow when added to the premises
How to test itNegate it: the conclusion should no longer followAdd it: the conclusion should be guaranteed
Can it say more than needed?No: a broader statement can be false while the argument still worksYes, as long as the conclusion follows

Common Traps

  • Choosing an answer that would help the argument but that it does not need. LSAC's explanation of its sample rejects one choice on exactly this ground: it might give a reason for what the argument claims, but it need not be assumed for the argument to succeed.
  • Choosing an answer that only tells you what the premises already establish. LSAC's explanation of its sufficient assumption sample rejects one choice because what it adds is something "we already knew".
  • Reversing a conditional. In the second example, (B) and (E) turn "every apprentice who finished the course" around, and neither closes the gap.
  • Rejecting the answer to a sufficient assumption question because it seems too strong. A sufficient assumption is allowed to say more than the argument needs.

How Should You Practice?

For each official question you work, decide first which kind it is from the wording of the question. Then run the matching test on every choice: negate for a necessary assumption, add for a sufficient one.
